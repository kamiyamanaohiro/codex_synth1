# codex_synth1

これは Web Audio API を用いた簡易グルーブボックスです。909 ライクなドラムマシーン、MS10 風のセミモジュラーシンセ、CS01 風のベースシンセの三つのモジュールを搭載しています。各シンセにはディレイを、ドラムマシーンにはリバーブを用意しました。UI はサイケデリックな配色になっています。

## 使い方
1. `public/index.html` をブラウザで開きます。
2. Start ボタンで再生、Stop ボタンで停止します。
3. 各モジュールのステップをクリックしてシーケンスを設定してください。

すべて純粋なクライアントサイドの実装なので追加のビルドは不要です。
